# HNH Labs 브랜드 에셋 (A3 · Mono)

서체 JetBrains Mono Bold (SIL OFL) — 모든 SVG는 글자를 패스로 변환해 폰트 없이 렌더링됩니다.

| 색 | HEX |
|---|---|
| Ink | #111114 |
| White | #FFFFFF |
| Gray (밝은 배경) | #8A8A90 |
| Gray (어두운 배경) | #9A9AA1 |

## 파일
- svg/logo-light|dark|black|white.svg — 워드마크 (웹 헤더·문서)
- svg/icon-*.svg, symbol-*.svg — 심볼 "h▮"
- png/app-icon-ios-1024.png — App Store (모서리 없음, iOS가 자동으로 둥글게)
- png/play-store-icon-512.png — Google Play
- png/android-chrome-maskable-*.png — 안드로이드 적응형 아이콘 (안전영역 여백 포함)
- favicon.ico / favicon.svg / apple-touch-icon.png / site.webmanifest — 웹사이트 루트
- png/og-image-1200x630.png — 링크 공유 미리보기
- head-snippet.html — <head> 태그 예시

## 사용 규칙
- 로고 주변 여백: 커서 블록 너비 이상
- 최소 크기: 워드마크 높이 16px, 그보다 작으면 심볼 사용
- 커서 블록은 항상 글자 오른쪽에, 회색은 ".labs"와 심볼 커서에만
